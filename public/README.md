# public/

Anything referenced from a composition lives here. Paths in props are relative
to this folder — `"clips/day0-front.mp4"`, not `"public/clips/day0-front.mp4"`.

```
public/
  clips/    footage and photos (mp4, mov, jpg, png)
  music/    background tracks and voiceovers (mp3, m4a, wav)
```

Raw footage is gitignored — it is too big for GitHub and does not belong in
git history. Keep the originals on your machine / in your own backup.
